# University Entry Gate Management System

## DBMS Assignment

### Topic
University Entry Gate Register

### Objective

The objective of this project is to design a database management
system for maintaining and monitoring the entry and exit records
of students, visitors, staff, vehicles and security personnel
within a university campus.

### Main Features

- Student information management
- Visitor information management
- Security guard management
- Vehicle management
- University gate management
- Entry and exit tracking
- Gate utilization analysis
- Visitor monitoring
- Security resource utilization
- Database views
- Triggers
- Stored procedures
- Functions

### Database Tables

The system contains the following main tables:

1. Student
2. Visitor
3. SecurityGuard
4. Gate
5. Vehicle
6. EntryLog
7. EntryLogAudit

### Technologies Used

- MySQL
- SQL
- GitHub

### Project Structure

- `01_Database_Creation.sql` – Database and table creation
- `02_Sample_Data.sql` – Sample records
- `03_Queries.sql` – Required SQL queries
- `04_Views.sql` – Database views
- `05_Triggers.sql` – Database triggers
- `06_Procedures_Functions.sql` – Procedures and functions

## Conclusion

The University Entry Gate Management System helps the university
maintain accurate entry and exit records and supports better
planning of gates, security personnel and campus resources.
